# Keyboard Shortcuts

JAAD includes a set of keyboard shortcuts to navigate the documentation without using the mouse.

## Search

| Shortcut                 | Action                          |
| ------------------------ | ------------------------------- |
| `Ctrl` + `K` / `⌘` + `K` | Open the search palette         |
| `↑` / `↓`                | Navigate through search results |
| `↵` Enter                | Open the selected result        |
| `Escape`                 | Close the search palette        |

The search palette can be opened from any docs page. The shortcut works even when focus is inside the docs content area.

## Page navigation

| Shortcut    | Action                  |
| ----------- | ----------------------- |
| `←` (Left)  | Go to the previous page |
| `→` (Right) | Go to the next page     |

Arrow key navigation is active whenever focus is not inside a text input, textarea, or select element.

> [!TIP]
> All keyboard shortcuts are registered globally and remain active across View Transitions navigation, so you never need to re-focus the page after clicking a link.
