# Keyboard Shortcuts

| Context | Shortcut         | Action                  |
| ------- | ---------------- | ----------------------- |
| Search  | `Ctrl+K` or `⌘K` | Open the search palette |
| Search  | `↑` / `↓`        | Select a result         |
| Search  | `Enter`          | Open the result         |
| Search  | `Escape`         | Close the palette       |
| Page    | `←`              | Open the previous page  |
| Page    | `→`              | Open the next page      |

Page shortcuts are disabled while an input, textarea or select has focus.
