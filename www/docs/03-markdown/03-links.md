# Links

```
[Inline link](https://example.com)
[Link with title](https://example.com "Hover tooltip")
[Other documentation pages](../../getting-started/installation)
<https://example.com> (autolink)
```

Create [inline links](https://example.com) to external sites. Link to [other documentation pages](../../getting-started/installation) using paths relative to the generated URL. Relative links continue to work when Astro's `base` option deploys the whole site below a subpath. The URL structure follows the file structure with numbered prefixes removed. Bare URLs like <https://example.com> are also automatically linked.
